# Serie A Match Statistics Preview

A lightweight, responsive frontend concept for a football match statistics tracker. It uses HTML, CSS, vanilla JavaScript, Chart.js, and Lucide icons.

## Open the preview

Open `index.html` in a modern browser. An internet connection is needed to load the Chart.js, Lucide, and font CDN resources. No install, server, sign-in, API, or database is required.

## Explore

- Start on the illustrated landing page and choose **Get Started**.
- Use the sidebar to move between the dashboard, matches, team statistics, league statistics, saved matches, and About.
- Search fixtures by either team, filter by season and round, and open a match with **View**.
- Change the selected team and chart metric on Team Statistics.
- Save matches with the bookmark controls and remove them from Saved Matches.
- The Events and Lineups tabs on a match show sample match events and fictional lineups.

Saved selections exist only in memory and reset on reload.
